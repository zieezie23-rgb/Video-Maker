1. CARA MEMULAI
---------------
1. Ekstrak file ZIP.
2. Buka file index.html menggunakan browser.
3. Gunakan Google Chrome versi terbaru untuk hasil yang paling kompatibel.
4. Aplikasi berjalan langsung di perangkat dan tidak mengunggah file ke server.

2. CARA MEMBUAT VIDEO
---------------------
1. Tekan "+ Pilih Gambar" lalu pilih satu atau beberapa gambar/video.
2. Pilih mode "Gabung" atau "Satu Frame".
3. Atur latar belakang, animasi, gerakan kamera, transisi, dan resolusi.
4. Atur ukuran serta posisi file pada area Pratinjau jika diperlukan.
5. Pilih pengaturan audio bila ingin menambahkan suara.
6. Tekan "Buat Video".
7. Setelah proses selesai, isi nama file lalu tekan "Unduh".

3. CATATAN FORMAT VIDEO
-----------------------
Format hasil bergantung pada dukungan browser. Pada browser tertentu, hasil
akan direkam sebagai WebM, bukan MP4. WebM tetap dapat diputar di banyak
pemutar video dan dapat dikonversi menggunakan aplikasi konversi lain.

4. TIPS
-------
- Jangan menutup tab selama proses render berlangsung.
- Untuk file besar atau video panjang, pastikan memori perangkat mencukupi.
- Jika tombol render tidak aktif, unggah setidaknya satu gambar atau video.
- Jika audio tidak terdengar, periksa izin suara dan coba gunakan Chrome.
- Watermark "zie's" muncul pada video hasil export.
